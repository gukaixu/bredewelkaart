# Brede Welkaart - Inclusive Wealth Index Nederland

**Interactieve kaart van het totale kapitaal in Nederland (2023)**

Deze webapplicatie toont de verdeling van natuurlijk, geproduceerd en menselijk kapitaal over Nederland op basis van de UNEP Inclusive Wealth Index (IWI) methodologie.

## 🌐 Live Demo

Bezoek: [bredewelkaart.nl/iwi](https://bredewelkaart.nl/iwi)

## 📊 Features

- **4 kapitaallagen**: Totaal, Natuurlijk, Geproduceerd, Menselijk
- **Balans indicator**: Toont hoe evenwichtig een regio presteert
- **5 administratieve niveaus**: Pixel (100x100m), Wijk, Gemeente, Provincie
- **Meerdere schalen**: Absoluut, Per Inwoner, Per Hectare, Aandeel (%), T.o.v. NL Gemiddelde

## 🛠️ Technologie

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Mapping**: Leaflet.js
- **Charts**: Chart.js
- **Type**: 100% statische webapplicatie
